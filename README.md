# rg-ape

ripgrep 14.1.1 as one portable `rg.com`, with Python, Node.js, and Java
bindings generated by [APEBind](https://github.com/nuwainfo/apebind).

This is a demonstration of APEBind. It is not a package to depend on.
`rg.com` is built by [rust-ape](https://github.com/bear0330/rust-ape) with
cargo_cosmo. The fat binary contains x86-64 and arm64. It has been run on
Linux x86-64.

## Try the Java jar

`rg-ape.jar` bundles `rg.com`. Java 17 or newer is enough:

```sh
javac --release 17 -cp rg-ape.jar examples/java/Search.java -d /tmp/rg-search
java -cp rg-ape.jar:/tmp/rg-search Search ape /path/to/directory
```

On Windows the classpath separator is `;`. No matches make `rg` exit 1, and
the binding raises `APEProcessException`. A match returns the text `rg`
printed.

The same call without the example class:

```java
import apebind.generated.rg_ape.RgAPEBinding;
import java.nio.file.Path;

String text = RgAPEBinding.search(
    RgAPEBinding.SearchParameters.builder()
        .pattern("ape")
        .path(Path.of("notes"))
        .lineNumber(true)
        .build()
);
```

`RgAPEBinding.raw(java.util.List.of("--version"))` runs an arbitrary argv and
returns stdout, stderr, and the exit code.

## Python and Node.js

The generated packages call the same binary. `scripts/prepare.sh` copies
`rg.com` into them. Set `RG_APE_RG` to the file produced by
`bash ./.github/scripts/collectbuild cli/rg` in a rust-ape superconfigure
tree.

```python
from rg_ape import search

print(search("ape", "notes", line_number=True))
```

```js
import { search } from "rg-ape";

console.log(await search({
  pattern: "ape",
  path: "notes",
  lineNumber: true,
}));
```

`search` accepts `ignoreCase`, `filesWithMatches`, `json`, `glob`, `hidden`,
and `noIgnore`. Python uses `snake_case` names. Node uses the names above.
A library call is not a terminal, so `rg` hides line numbers unless
`line_number` / `lineNumber` is set.

## Rebuild the jar

```sh
RG_APE_RG=/path/to/rg.com ./scripts/prepare.sh
./scripts/build-java.sh
```

Regenerate the bindings from the reviewed schema:

```sh
apebind validate rg.apebind.yaml
apebind generate rg.apebind.yaml --ape rg.com --lang python -o bindings/python
apebind generate rg.apebind.yaml --ape rg.com --lang node -o bindings/node
apebind generate rg.apebind.yaml --ape rg.com --lang java -o bindings/java
```
